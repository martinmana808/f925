# F925 | Project Brain

## Project Summary
A premium landing page and showcase for "AI That Works in the Real World". Built with React, Vite, Tailwind CSS, and Framer Motion.

## Tech Stack
- **Framework:** React 19
- **Build Tool:** Vite 6
- **Styling:** Tailwind CSS (via CDN in index.html)
- **Animations:** Framer Motion
- **Icons:** Lucide-react
